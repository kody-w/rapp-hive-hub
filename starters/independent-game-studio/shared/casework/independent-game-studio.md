# The Independent Game Studio

Ship a small original game, with a real production discipline.

Run a seven-team independent studio around Mosslight Courier, an original offline route puzzle. Turn synthetic first-session feedback into a bounded onboarding revision with playable source, readable art, opt-in sound, and reproducible regression evidence.

## Rooms

- `shared/production/`: producer. Own the first-shift scope, review gates, and a conditional release decision without claiming a shipped product.
- `shared/design/`: game-designer. Specify understandable bridge, carrying, delivery, and undo rules within the existing three-board game.
- `shared/engineering/`: game-engineer. Maintain the deterministic engine and keyboard-first offline browser build.
- `shared/art/`: game-artist. Create original high-contrast symbols and a small coherent visual asset system.
- `shared/audio/`: sound-designer. Specify restrained, opt-in, locally synthesized event cues with a silent fallback.
- `shared/quality/`: qa-lead. Check solvability, input handling, no-network behavior, accessibility limits, and regressions.
- `shared/player-research/`: player-researcher. Separate the synthetic feedback exercise from real observations and design the next consent-based playtest.
- `shared/casework/`: the shared delivery case. Its intake is [[first-shift-onboarding]]; shared inputs sit in `artifacts/`; accepted deliverables land here too.

Related starters, for discovery only (never shared membership): `product-launch-company`.

All names, estimates and observations are synthetic public starter data.
