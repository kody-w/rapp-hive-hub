A Hive template for the Hive folder convention (`hive-md`, experimental): 7 team rooms and a
casework room, 12 tasks linked by their dependencies, the charter, the first case (Line Ledger:
repair duplicate counting and out-of-order state reduction) and 16 starter files. All data is
synthetic, and nothing in it runs.

Pull it down read-only and let your Brainstem's Hive agent create a new Hive from it. Its README
says how, and what does not map cleanly.
